1. 結論

這套 GitHub 對本專案的價值在表徵設計的先例與對照組，不在可執行的工具。六個儲存庫裡能跑的程式只有四支純 Python 後處理；六個都沒有 LICENSE，法律上只能重寫、不能取用。本頁只放清單與複查結果；逐項關聯判斷在 07 方法對照，可借與待辦在 09，時間在 08。

3. 工具清單（六個儲存庫，開源頁宣稱五個）

實驗室帳號 International-Digital-Oral-History-Lab

儲存庫 是什麼 可執行？
IDOHL-updator 網站 Updates 頁的新聞聚合器。Node 20＋cheerio，GitHub Actions 每週一、四 06:15 UTC 抓 UCL Information Studies 新聞（HTML 爬取）與 TU Darmstadt HDSM 部落格的 digital_oral_history_lab 分類（RSS），寫 landing_page/data/news-cache.json 供 Omeka S 頁面讀取。9 個檔案 可，但與口述歷史研究無關
MDOH_Project 只有 README；README 列的 data/、docs/、src/、notebooks/、outputs/、references/ 六個資料夾都不存在 無程式
MeDoraH_Project 只有 README；README 預告五個子儲存庫 medorah/medorah-kg、-api、-tools、-datasets、-analysis，三個標 Coming Soon，2026-10-13 複查仍未建立（medorah 是舊帳號名，已改名為 International-Digital-Oral-History-Lab，轉址仍在；五個儲存庫在新舊名下都沒有） 無程式

研究員帳號 articoder（Jiajie Zhang，UCL）

MeDoraH_NLP，四個元件：

元件 內容 可執行？
NarraGraph v0.4.0 Tauri 2／React 19／Rust 桌面程式。功能依 release 說明：LLM 三趟抽取、本體映射、網絡分析（時序社群追蹤、虛無模型、快照比較、冪律擬合、加權中心性）、SPARQL playground、Parallel Reading（原文與譯文並排）、research copilot、本機 LLM 面板與反向代理端點 只有安裝檔（9 個 release，macOS／Windows／Linux）。九個 tag 指同一 commit，原始碼不在任何公開儲存庫
Preprocessing 2 支 Python：正規表示式切句、產生「前一組／當前組」話輪對 可
Dashboard／Network Analysis generate_report_modern.py（Jinja 單檔 HTML 儀表板，統計主詞型別→關係→受詞型別的結構模式、基數、定義域／值域多樣性）、semantic_triple_analysis.py（networkx 有向圖、degree 與 betweenness、pyvis 輸出） 可，純程式、不呼叫模型
Clustering 6 支 Python：UMAP＋HDBSCAN 述詞嵌入分群、WordNet 動詞上位詞命名、網格評估、Pareto 前緣 不可：輸入 parquet 在作者本機路徑，產生嵌入的 embedding_analyzer 套件不在儲存庫
其他 Ontology Visualiser 互動 HTML；19 卷 Hidden Histories 英語訪談話輪 JSON（無時間碼）；1,647 筆 LLM 抽取結果、304 筆本體映射示範；15 個 Google Jules 機器人分支（網站 HTML 無障礙修正） 資料可讀

MeDoraH_Ontology：三個 Turtle 檔（內容層本體 43 類／51 物件屬性；檔案層本體含 SpeechSegment 的 startTime／endTime／speaker；OHA 1.1 對映 Dublin Core 的中繼資料詞彙 V3）、OmniGraffle 圖、Palladio 手工編碼網絡 CSV（366 實體／598 關係，RelationType 1 到 16 無對照表）。只有資料與文件，README 列的 /tools 與 /extensions 不存在。

開源頁宣稱與事實：頁面稱「五個儲存庫、遵循開源最佳實務」；實際六個（含 updator）、零個 LICENSE；NarraGraph「open source via MeDoraH_NLP」只對應安裝檔。能從公開檔案跑到底的只有「抽取 JSON → 儀表板／網絡圖」那一段。 來源：03 筆記第 1 至 7 節；gh api 'repos/International-Digital-Oral-History-Lab/IDOHL-updator/git/trees/main?recursive=1'；https://raw.githubusercontent.com/International-Digital-Oral-History-Lab/IDOHL-updator/main/scripts/README.md
