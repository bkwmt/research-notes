五個橫向發現（寫 related work 可直接用）

  1. 沒有任何一篇同時做到「非三元組表示＋每筆強制出處＋中文口語語料」三件事。 這正是本專案的空白區與貢獻點。最接近的各只沾一角：GraphRAG 有非三元組（社群摘要）但無出處、 Blouin 有中文與細緻實體連結但無 LLM、Cherukuri 有口述歷史但只做分類、AgentRE 有中文但純三元組無出處。

  2. 表示法其實有一道光譜，不是只有「三元組 vs 其他」。 從最窄到最寬：純三元組（pan2024、KARMA、Graphusion、AutoKG、AgentRE、Text2KGBench）→ 受本體約束的三元組（Text2KGBench、Graphusion 七類）→ 屬性圖（Buehler、Agentic-KGR）→ n-ary／事件框架（xu2024 收錄）→ 文字摘要節點（GraphRAG 社群摘要）→ 帶標籤句子（Cherukuri）。 本專案的「實體／事件／關係／goût＋出處」混合結構落在這道光譜偏寬的一端，且多了一個沒人做的維度：主觀評價（goût）。

  3. 評估分成兩派，本專案該站「程式化免 gold standard」這一派。 程式化派（不需標準答案、無 LLM 評分）：Text2KGBench 的本體符合度＋幻覺、KGGen 的 MINE 還原率、 Strutz 的分層部分給分、fang2025／Blouin／NER4all 的人工 gold＋P/R/F1。 LLM 自評／評審派（踩紅線 2）：KARMA（全流程 LLM 判）、GraphRAG（0–100 自評分＋LLM 兩兩對比）、 Agentic-KGR（模型自吐信心＋LLM 蒸餾 gold）。gu2024 的後設評估實驗正好證明後者不可信。

  4. 真正測過中文的只有 4 篇，真正對「口語逐字稿」做結構化抽取的是 0 篇。 中文：AgentRE（DuIE）、AutoKG（DuIE2.0）、fang2025（繁中民國期刊）、Blouin（繁中申報）—— 全是書面文本。Cherukuri 唯一碰口述訪談，但語料是英文、任務是分類。本專案的「繁中口語逐字稿＋ASR 錯字＋臺語詞彙」 是所有文獻都沒測過的條件。

  5. 「harness／agentic 用在人文資料並報告結果」在學術上還沒發生。 Yehudai 明講「解耦 LLM 與 harness 評估」才剛起步、benchmark 全是英文工程領域； Bian、Pan 的地圖裡 agentic 抽取幾乎無處安放。本專案的方法論新意不在工具，在於把它接到無 gold standard 的口述史料並設計出可信評估。

一句話總結

主流文獻把知識窄化成「無出處的乾淨三元組」，用 LLM 自評或 LLM 互評來衝高分數； 少數程式化、免 gold standard 的評估（Text2KGBench、Strutz、KGGen-MINE）和把領域知識寫進脈絡的做法 （AgentRE、NER4all）指出了可行路徑。本專案的位置，是把這些零散的可行元素——兩層 harness（Graphusion）、 判準即檔案（AgentRE／NER4all）、程式化免 gold 評估（Text2KGBench／Strutz）、可追溯日誌（fang2026）—— 接到一個所有文獻都沒碰過的組合上：繁體中文口語逐字稿的結構化抽取，非三元組的混合表示，每筆強制附出處。
